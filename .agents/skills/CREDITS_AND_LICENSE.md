# Credits and License

This directory contains skills that demonstrate what's possible with Claude's skills system, adapted from Anthropic's reference implementations.

Many skills in this repository are open source (Apache 2.0).
We have also included document creation & editing skills (e.g. `docx`, `pdf`, `pptx`, and `xlsx`) that power Claude's document capabilities. These are source-available, not open source, but shared as a reference for more complex skills.
